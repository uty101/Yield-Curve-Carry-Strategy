**Deviation from the plan, stated in full (an endpoint fact, not a choice).** PLAN.md 1.6 names the per-tenor catalog datasets `fm-d-fr-eur-fr2-bb-frmoytec<N>-hsta` and their `/exports/csv`. Those datasets exist in the catalog but are empty shells: `has_records: false`, `records_count: 0`, `fields: []`, with a valid key and without, via header and via query parameter. The observations live in the catalog dataset **`observations`** (10.2 M rows, keyed by `series_key`), reachable only with the key (without it that dataset 404s). The loader therefore calls
`GET …/catalog/datasets/observations/exports/csv?where=series_key="FM.D.FR.EUR.FR2.BB.FRMOYTEC<N>.HSTA"`.
The series, tenors, units and the key rule are exactly as planned. `decisions/euro_curves.md` should be updated with the endpoint and the first date — done in this commit.
