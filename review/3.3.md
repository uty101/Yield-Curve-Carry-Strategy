**Rules stated in full.** Chart 2 is three panels, PC1 to PC3, loading
against tenor, one line per country and the **primary** pooled fit dashed
black. Each country is drawn on its own tenor set, so the lines end at
different tenors. `pooled_20y` is **not drawn**: it is a reported robustness
column, and a seventh line on the same axes would read as a seventh country.
The table is percent to one decimal place, and the `PC1-3` column is the sum
of the **rounded** components so the printed row adds up.
