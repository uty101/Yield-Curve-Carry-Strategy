### The rule this step is built on

`test_section_6_3_has_no_hardcoded_numbers` parses `caveats.section` with
`ast` and fails on any `int` or `float` constant outside a `FormattedValue`.
`test_the_guard_would_catch_a_typed_number` proves the guard is not vacuous by
running it against a function that does type one. The only way a number
reaches the page is `facts`, and every entry of `facts` names the file it came
from in a comment beside it.

### Deviation 5 — the section is its own module

PLAN.md 6.3 puts the function in `report.py`. It reads nine files and holds a
page of prose, and `report.py` is already the metrics table, the
explained-variance table and the unhedged FX regressions. It lives in
`curvecarry/caveats.py`; `report.section_what_carry_does_not_tell_you` is kept
as the plan's entry point and `test_plan_entry_point_is_the_same_text` asserts
the two return the same string. PLAN.md 6.3 is amended.

### Deviation 6 — the on-the-run tenor comes from config

The section quotes the US CMT-versus-GSW gap at one tenor. Which tenor is a
number that affects a reported result, so under global rule 4 it is not a
literal: it is `config.sample.sample_max_tenor`, the project's own benchmark
tenor, which is 10. PLAN.md 6.3 is amended to say so.

## Not verified

- The `metrics_table.csv` the section reads is the one step 5.5 left behind
  and does not yet contain the six risk-control runs; 6.4 rewrites it with
  every logged variant and the section is regenerated from that. The figures
  the section quotes from it (headline, interbank, country scope, GB 30-year,
  both cost rows) are not affected, because those variants and their returns
  do not change; only the deflated-Sharpe columns do.
- `_basis_range` lifts the range from `decisions/basis.md` with a regular
  expression. If that sentence is reworded the section falls back to
  "unquantified" rather than failing. A test that asserted the match would be
  a test of the prose in a decision file, which is not what tests are for
  here; the fallback is visible in the output.
