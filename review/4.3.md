**Definitions stated in full.** `r_hedged = r_excess_local`: under covered
interest parity the FX-hedged excess return in the base currency **is** the
local excess return, and no exchange-rate series enters it
(`decisions/basis.md`). `fx_return = ln S_{t+1} − ln S_t` with `S` in base per
foreign, so a foreign appreciation is a gain.
`r_unhedged = r_local + fx_return − r_short_base/12`.
`hedge_carry = (r_short_base − r_short_local)/12` is a diagnostic; nothing
reads it. For the base country all three returns coincide and both FX terms
are zero.

**One deviation from the plan.** The plan named the CLI step `fx`. That is
already the name of the step-1.7 FX *loader* in `cli.LOADERS`, and a build
step of the same name shadows it, so `build --all` would have silently
stopped rebuilding `data/interim/fx.parquet`. Renamed to `fx_hedge`, and
PLAN.md 4.3 amended in the same commit.

## Not verified

- **That the ECB Data Portal really has no basis series.** It returned
  HTTP 503 on both the dataset list and the search endpoint on 2026-09-23,
  so the finding for that source is "not reached", recorded as such in
  `decisions/basis.md` and treated as a negative. Re-running the two URLs on
  a day the portal is up would settle it. It would not change `r_hedged`:
  a basis series enters as an additive adjustment and is not in the pipeline
  either way.
- **That the size of the omitted basis is the brief's 20 to 50 bp for these
  six currencies over this sample.** That is the brief's number, quoted, not
  measured here.

## Open

- **GB 1970 has no FX and the amendment did not expect it.** Amendment 3
  asked for the months where hedged exists but unhedged does not, and named
  DE and FR. The euro ones are there (DE, 17 months); FR has none; and
  there are 12 GB months in 1970 because `DEXUSUK` starts 1971-01 while the
  BoE curve starts 1970-01. They are logged like the euro ones and are 27
  years before `strategy_start`, so nothing in the strategy sample is
  affected. Flagged because it is a case the amendment's wording rules out
  and the data does not.
